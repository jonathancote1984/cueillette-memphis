# 📍 Vos spots

Un **spot**, c'est un coin de cueillette que vous voulez retrouver. Vous pouvez y noter son nom,
sa position GPS, une photo et les espèces que vous y trouvez.

## Créer un spot

1. Allez dans l'onglet **📍 Spots**.
2. Appuyez sur le bouton rond **＋** (en bas à droite).
3. Donnez un nom facile à retenir, par exemple *« Derrière le gros érable »*.
4. Ajoutez la **position GPS** avec le bouton *« Utiliser ma position »* (l'app affiche la précision).
5. Ajoutez une **photo** (appareil ou galerie) et, si vous voulez, la **liste des espèces** que vous y trouvez.
6. Appuyez sur **💾 Enregistrer**.

> 🗺️ Votre spot apparaît ensuite avec un **lien pour l'ouvrir dans Google Maps** — bien utile pour y retourner.

## Modifier ou supprimer

- **✏️ Modifier** : ouvrez le spot, changez ce que vous voulez.
- **🗑️ Supprimer** : l'app vous demande une **double confirmation** avant d'effacer, pour éviter les erreurs.

## Conseils terrain

- En forêt, la position GPS peut être imprécise : **vérifiez la précision affichée** avant de valider.
- Ajoutez une **photo repère** (un arbre, un cours d'eau) pour retrouver le coin facilement.
- Notez les **espèces** que vous y avez vues : vous saurez où retourner à la saison.
