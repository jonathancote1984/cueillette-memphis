# 📊 Vos statistiques

L'onglet **Stats** résume votre activité : tout se met à jour automatiquement à partir de vos récoltes.

## Ce que vous voyez

- **Total récolté** — le poids cumulé de toutes vos cueillettes.
- **Sorties** — le nombre de cueillettes enregistrées.
- **Espèces** — combien d'espèces différentes vous avez trouvées.
- **Dernière sortie** — la date de votre dernier passage.
- **Tops** — vos espèces et vos spots les plus récoltés.
- **Barres mensuelles** — votre récolte mois par mois, avec un code couleur.

## À quoi ça sert

- **Se fixer des objectifs** de récolte (poids, sorties, espèces).
- **Repérer vos meilleurs coins** (tops spots) pour y retourner.
- **Suivre la saison** : les barres mensuelles montrent vos moments les plus productifs.

## L'onglet Stats contient aussi la sauvegarde

Le bas de l'onglet Statistiques regroupe les actions importantes :

- 📤 **Exporter** — télécharge une **copie de sauvegarde** de tout votre carnet.
- 📥 **Importer** — restaure une sauvegarde (utile si vous changez de téléphone).
- 🗑️ **Tout effacer** — efface tout, avec double confirmation.

> 🔒 **Exporter régulièrement** : vos données vivent uniquement sur votre téléphone. Une sauvegarde vous les protège si vous le perdez ou changez d'appareil.
