# 🍄 Bienvenue dans Cueillette Québec

L'app pour noter vos **coins de cueillette**, **identifier** les champignons dans le guide et
**tenir votre journal de récolte** — le tout **100 % hors-ligne**, directement sur votre téléphone.

> 💡 **Vos données restent sur votre appareil.** Pas de compte, pas de serveur, pas d'abonnement.

Les 5 onglets en bas d'écran :

| Onglet | À quoi ça sert |
|---|---|
| 📍 **Spots** | Enregistrez vos coins secrets (nom, position GPS, photo). |
| 🍄 **Identifier** | Guide de 21 espèces québécoises + checklist terrain + identification par photo (IA). |
| 🧺 **Cueillettes** | Notez chaque récolte : date, espèce, poids, spot, météo. |
| 📊 **Stats** | Total récolté, nombre de sorties, espèces, tops, barres mensuelles. |
| ⚙️ **Paramètres** | Unités kg/lb, clé d'identification IA, crédits photos, ce guide. |
