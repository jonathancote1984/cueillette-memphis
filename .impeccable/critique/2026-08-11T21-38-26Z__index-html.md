## Problèmes prioritaires

**P1-1 — « Tout effacer » ne vide pas le store `checklist`** (index.html:2218-2219) — toast « toutes les données effacées » mensonger, coches fantômes. Fix : `vider('checklist')`.

**P1-2 — Retour fiche détail : aucun onglet actif** (naviguer('detail') ne matche rien), retour en bas après ~3000 px de scroll. Fix : bouton « ← » sticky dans le header quand vue === 'detail'.

**P2-1 — Focus ambre seulement sur les champs** — boutons/puces/items/FAB en outline navigateur. Fix : `:focus-visible` ambre partout.

**P2-2 — Contrastes : libellé « Espèces » noir 80 % sur olive = 3,56:1** (passe 6 a oublié olive) ; sous-titre header 4,22:1 sur #C87224.

**P2-3 — Catch identification photo affiche `err.message` brut** — contourne le fix passe 6. Fix : `messageErreurIA(err)`.

**P2-4 — Puces saison actives sans couleur** (seulement rotate -2°). Fix : fond noir/ambre pour `[data-fs]` actif.

## Red flags personas

**Forêt (une main)** : pire moment = comparer amanite rougissante/panthère → 3000 px de scroll pour « ← Retour ».
**Clavier/lecteur d'écran** : focus invisible, lightbox sans role=dialog ni Escape, imbrication role=button + `<button>`.
**Pressé/prêt du téléphone** : « Tout effacer » laisse les coches → anciens verdicts ✅ réapparaissent sur fiches mortelles.
