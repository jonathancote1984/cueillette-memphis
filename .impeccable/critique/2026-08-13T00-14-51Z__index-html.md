## Forces (3)

1. **Système de verdicts à vérité unique** (⚠️/✅/☠️, valence parfaite, dynamique n/n, monté sous l'alerte).
2. **Boucle de comparaison fiche→fiche fluide** (scroll mémorisé, nom espèce header, ← sticky).
3. **Discipline Memphis totale** jusque dans les micro-détails (tabular-nums, hit-area, focus trap, Escape).

## Problèmes prioritaires

**P1-1 — Les synonymes vernaculaires mortels ne déclenchent aucun badge** : « fausse morille » (gyromitre) et « ange destructeur » (amanite vireuse) — littéralement dans les noms du guide — échouent au matche flou (distance ≥ 13) → journal sans badge rouge pour des espèces MORTELLES. Fix : matche par inclusion + alerte « Voulez-vous dire… » à la saisie.

**P2-1 — Analyse photo IA 10-20 s sans annulation** ; si la feuille est fermée, le résultat (potentiellement MORTEL) est réécrit dans une feuille fermée, invisible. Fix : AbortController + bouton annuler, ou ré-ouverture + toast.

**P2-2 — Import sans vérification de `data.version`** : un vieux export avale la checklist, toast « Import réussi ✅ ». Fix : avertissement si version < 5, refus si version > 5.

**P3-1 — « 📷 Réessayer » rouvre la galerie** au lieu de répéter la source.
**P3-2 — Lightbox sans restauration du focus** à la fermeture.

## Red flags personas

**Power user** : import destructeur sans avertissement.
**A11y** : focus perdu après lightbox.
**Mobile forêt** : synonyme mortel sans rouge ; analyse IA perdue dans une feuille fermée.
