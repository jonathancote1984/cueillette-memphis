## Problèmes prioritaires

**P1-1 — Nom latin illisible (2.56:1)** : `.ligne-latin` opacité .65 (l.332) — l'outil de désambiguïsation n°1 est le texte le plus pâle de l'app. Fix : opacité .85 (~4.9:1).

**P1-2 — Bouton 🗑️ du guide promet la destruction, exécute le masquage** (l.1314) : collision sémantique. Fix : icône 🙈 (ou ⋯) + title « Masquer ou supprimer » sans corbeille.

**P2-1 — Trois micro-textes sous AA** : `.info-gps` 3.36:1 (l.202), `.mois-col .lab` 2.86:1 (l.325), `.stat-carte .libelle` carte 1 3.27:1 (l.306, les cartes 2-4 corrigées, la 1 oubliée). Fix : opacité 1 ×3.

**P2-2 — Zoom image de fiche inaccessible au clavier** (l.1366) : `cursor:zoom-in` sans role/tabindex. Fix : role=button + tabindex + aria-label.

**P2-3 — `title` des zones photo ment quand vide** (l.521/569/626) : « Cliquez pour retirer la photo » alors que le clic ouvre la galerie. Fix : title dynamique dans `afficherPhoto`.

**P3-1 — `font-weight:900` hors plage chargée** (l.259/262). Fix : 700.
