## Problèmes prioritaires

**P1-1 — « 🗑️ Masquer » dans la fiche détail** (l.1374) : le correctif 🙈 de la 11e n'a été appliqué qu'à la liste (l.1326) — deux surfaces, deux icônes pour la même action réversible. Fix : « 🙈 Masquer » dans la fiche.

**P2-1 — Toast « Analyse terminée ✨ » sur échec d'identification** (l.2153) : fausse célébration au pire moment (forêt). Fix : toast conditionnel.

**P2-2 — Fiche détail sans aucun heading** (l.429-431, contenu l.1376-1390) : navigation par titres impossible pour lecteurs d'écran sur l'écran le plus dense. Fix : nom = h2, guide-sujet = h3.

**P2-3 — Modale de choix sans focus initial** (l.1056-1065) alors que `confirmer` focus « Annuler ». Fix : `$('choix-masquer').focus()`.

**P2-4 — Micro-textes résiduels sous AA** : `.vide-etat` .8 → 3.99:1 (l.335), note spot .75 → 3.36:1 (l.528). Fix : opacity 1 ×2 + règle « ≤13px à opacité < .85 interdit ».

## Red flags personas

**Power user** : piège 🗑️/🙈 dans la fiche ; import sans champ version passe sans alerte.
**A11y** : fiche sans headings + modale sans focus + role=button imbriqués.
**Mobile forêt** : toast ✨ sur échec ; chevauchement nom+badge+bouton 🙈 sur petit écran.

## Observations mineures

Rangs colorés par position ; COULEURS_MOIS hors saisons ; graphique mensuel sans valeurs ; « 5/5 » en dur dans la carte d'aide (l.464) alors que les critères sont variables ; img de spécificité cliquable non focusable ; lightbox sans focus trap ; « guide » vs « Identifier ».
