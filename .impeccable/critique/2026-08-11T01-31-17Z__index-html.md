## Forces (3)

1. **La fiche hybride terrain (checklist + verdicts fail-safe)** — le mécanisme le plus abouti : 5 spécificités avec photos réelles Wikimedia embarquées, descriptions orientées action, coche olive barrée, compteur n/5, verdict ⚠️/✅ persistant, fail-safe « Rien n'est encore vérifié → on ne mange pas » qui survit à la décoche totale.
2. **La discipline du design system au pixel** — les règles nommées du DESIGN.md tenues sans exception (Trait Noir, Décalage Net, Rouge Mortel). Le style n'est pas un habillage, il est le produit.
3. **Le système de réassurance sécurité, sans panique** — alerte « Règle d'or » permanente, MORTEL + antipoison systématiques, double confirmation, alerte « Jamais exporté », badge conservé sur espèces supprimées, fail-safe de vocabulaire IA.

## Problèmes prioritaires

**P1-1 — La checklist terrain ne survit pas à l'export/import (perte de données silencieuse).** L'export embarque spots, cueillettes, especesCustom, illustrations, cachees, supprimees — pas le store `checklist`. La note d'export promet « transfert vers un autre téléphone » : toutes les vérifications ⚠️/✅ disparaissent au transfert sans aucun message. *Fix : `checklist: Object.values(Etat.checklist)` à l'export (version 5) + relire à l'import.*

**P1-2 — La checklist est indexée par position : retirer une spécificité corrompt les coches.** `retirerIllu(i)` fait `splice` des items sans ajuster `faits[]` → toutes les coches suivantes se décalent, verdict erroné possible sur fiche mortelle. *Fix : réindexer `faits` dans `retirerIllu` + re-dériver le verdict.*

**P2-1 — Contrastes AA manquants sur 2 libellés de stats.** `.stat-carte:nth-child(2)` (cuir) et `:nth-child(4)` (terracotta) : blanc 80 % → 4.15:1 et 3.74:1. *Fix : opacité .8 → .95 ou blanc pur.*

**P2-2 — Filtres de sécurité du guide incomplets.** 4 puces pour 5 statuts + prudence : « Immangeable » (bolet amer) invisible sous Toxiques, pas de filtre Prudence (morille, amanite rougissante). *Fix : puce « ⚠️ Prudence » + fusionner « Toxiques + Immangeables » en « Ne pas manger ».*

**P2-3 — Erreurs techniques brutes exposées.** `Failed to fetch`, `Génération impossible : ...` — err.message anglais sans guidance. *Fix : mapper les erreurs connues (réseau, clé, quota) vers des messages français avec l'action suivante.*

*(P3)* **P3-1 — Modales sans focus trap ni Échap ; lightbox non clavier.** Fix : piège de focus + Échap, role="dialog" + bouton fermer sur la lightbox.

## Observations mineures

- CSS orphelin : `.illu-onglets` / `.illu-img` (ancienne galerie)
- Double alerte orange « clé Gemini » dans sheet-espece (L576 + L628)
- `font-weight:900` sur .spec-num et .spec-carre — hors échelle 400-700
- `saisonDe` classe par premier mois cité : chanterelle invisible en automne, pleurote jamais en hiver
- Import sans validation de version (accepte tout JSON de forme valide)
- Verdict ✅ olive possible sur fiches MORTELLES (valence discutable)
- `.item .mesures` vert #0B7A55 codé en dur — 3e variable verte non documentée
- Tiges de mois vides à 4px minimum : suggèrent une micro-récolte
- Placeholders avec emojis : disparaissent au focus sur certains navigateurs
